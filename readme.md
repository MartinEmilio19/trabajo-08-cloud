# 🎬 Proyecto Web - Leyendas del Cine de Acción

Este proyecto consiste en una página web creada con **HTML y CSS** que muestra información de dos grandes protagonistas del cine de acción: **Sylvester Stallone** y **Jean-Claude Van Damme**.  

La estructura del proyecto está diseñada para mostrar imágenes y descripciones de manera ordenada utilizando contenedores y estilos visuales modernos.
